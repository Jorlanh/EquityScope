# Figuras do relatório

As figuras são geradas por `src/16_gerar_graficos_relatorio.py` depois da instalação de `requirements.txt`. O script `src/17_gerar_graficos_svg.py` também gera uma versão SVG sem depender de Matplotlib.

- `01_gini_comparacao_paises.png`: evolução do Gini nos países selecionados.
- `02_hiato_genero_comparacao_paises.png`: hiato de remuneração entre mulheres e homens.
- `03_brasil_genero_raca_pnad.png`: rendimento brasileiro por sexo e cor ou raça.
- `04_inclusao_financeira_genero.png`: diferença de acesso a contas por gênero.
- `05_gini_medio_por_regiao.png`: resumo regional do Gini.

As versões `.svg` têm os mesmos cinco gráficos e podem ser abertas diretamente no navegador.

Os gráficos são descritivos. Eles não substituem o dicionário das variáveis nem autorizam comparação entre categorias que não sejam metodologicamente compatíveis.
